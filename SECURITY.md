# Security policy

## Supported versions

Security fixes are provided for the latest release and the `development` branch. Older releases are not supported.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private reporting instead: go to the
repository's **Security** tab and choose **Report a vulnerability**. If that is not available, contact the maintainers
through the project's contact details at <https://wildintel.eu/>.

Please include the affected version, a description of the problem and, if possible, steps to reproduce it.

CamTrap Verify runs locally on the user's computer (or on a server the user controls) and reads camera-trap data and
images from local folders and, optionally, from a Trapper server. Reports about path handling, file access or
handling of credentials are especially welcome.

## What to expect

Reports are handled on a best-effort basis while the WildINTEL project is running and by the community afterwards;
there is no guaranteed response time. We will acknowledge the report, work on a fix and credit the reporter in the
release notes unless they prefer to stay anonymous.
